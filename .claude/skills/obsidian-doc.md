# Obsidian 文档管理规范 — 大周天项目

管理 `D:\Obsidian\30-项目\大周天\` 下的所有设计文档，确保结构清晰、信息不腐、可回档。

## 触发条件

当用户执行以下操作时调用此技能：
- 说「记录到 Obsidian」「更新文档」「整理文档」「写到笔记」
- 新增/修改/删除设计文档
- 说「备份文档」「存档」「回档」
- 观察到过时信息或文档结构混乱

## 核心规则

### 规则 1：模块文件夹结构（固定 8 模块）

```
大周天/
├── 大周天 项目仪表盘.md          ← 总索引
├── 01-架构设计/                  ← 游戏架构、设计决策总表
├── 02-卡牌系统/                  ← 卡牌架构、升级、工厂、字段
├── 03-战斗系统/                  ← CombatActor、FSM、AI、结算
├── 04-经脉系统/                  ← 流体、回路、碰撞、可视化
├── 05-功法系统/                  ← 功法树、转化机制
├── 06-丹药系统/                  ← 丹药、奇遇、副作用
├── 07-UI系统/                    ← 风格、色板、组件
└── 08-开发日志/                  ← Bug修复、审计、踩坑记录
```

- 新文档必须归入已有模块
- 需要新模块时，编号从 09 往上递增，更新仪表盘
- 禁止把文档扔在根目录（除仪表盘外）

### 规则 2：文档模板

每个 `.md` 文件必须包含 frontmatter：

```yaml
---
tags: [<模块名>, <二级标签>, 大周天]
created: <YYYY-MM-DD>
updated: <YYYY-MM-DD>
---
```

示例：

```yaml
---
tags: [卡牌系统, 架构, 大周天]
created: 2026-06-02
updated: 2026-06-02
---
```

- `tags` 第一个永远是模块名（对应文件夹名）
- `created` 首次创建日期，`updated` 最后修改日期
- 每次编辑后更新 `updated`

### 规则 3：仪表盘双向维护

每次增删文档时必须同步更新 `大周天 项目仪表盘.md` 的模块索引。

格式：
```markdown
- [[路径/文件名|显示名]] — 一句话描述
```

新增文档 → 加到对应模块下
删除文档 → 从仪表盘移除对应行
重命名 → 更新仪表盘链接

### 规则 4：即时清理

以下情况立即删除：
- 已经被新文档完全覆盖的旧版
- 过时的草稿/临时记录
- 重复信息的第二份

以下情况合并而非删除：
- 两份文档内容高度重叠 → 合并到较新的那篇，删除旧的
- 小碎片笔记聚合成主题文档 → 删除碎片

清理前先检查 git 状态确认已有备份。

### 规则 5：Git 备份

仓库位置：`D:\Obsidian\30-项目\大周天\.git`

**每次修改文档后必须 commit：**

```bash
cd "D:\Obsidian\30-项目\大周天"
git add -A
git commit -m "<简短描述>"
```

Commit message 规则：
- 新增文档：`add: <文档名>`
- 更新文档：`update: <文档名> — <改了什么>`
- 清理文档：`clean: <文档名> — <原因>`
- 结构调整：`refactor: <改动描述>`

**查看历史：**
```bash
git log --oneline -10
```

**回档到上一个版本：**
```bash
git log --oneline          # 找到目标 commit hash
git checkout <hash> -- <文件路径>
```

**回档整个 vault：**
```bash
git reset --hard <hash>
```

## 工作流程

### 新增文档

```
1. 确认归属哪个模块文件夹
2. 用模板创建 .md 文件（frontmatter + 内容）
3. 写完后更新仪表盘索引
4. git add + commit
```

### 更新文档

```
1. 读旧文档 → 确认变更范围
2. 编辑内容 + 更新 frontmatter.updated
3. 检查是否有其他文档引用本文档（wikilink）→ 确保链接不断裂
4. git add + commit
```

### 清理文档

```
1. 确认 git 已有备份（最近一次 commit 可见）
2. 删除或合并
3. 更新仪表盘
4. git add + commit (message 注明 clean)
```

### 回档文档

```
1. git log --oneline 找目标版本
2. git checkout <hash> -- "文件路径"
3. 如果需要放弃最近多次改动: git reset --hard <hash>
4. 更新仪表盘（如果回档影响了索引）
```
